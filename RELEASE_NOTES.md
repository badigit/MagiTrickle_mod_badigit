## Маршрутизация и конфигурация

- **Защита конфигурации.** Сбой записи больше не оставляет частично записанный `config.yaml`. Если новый конфиг не читается или не проходит проверку, демон сохраняет действующие настройки. При старте с повреждённым конфигом демон сообщает об ошибке и завершает работу.
- **Обновление групп.** При ошибке массовой замены групп MagiTrickle восстанавливает прежние правила. Изменение имени или цвета группы сохраняет её приоритет в маршрутизации. Несовпадение ID в запросе на изменение группы больше не отключает её правила.
- **Стабильность маршрутизации.** Исправлена временная потеря нужных записей ipset при одновременном переключении маршрутизации и изменении правил. Очистка TProxy и маршрутов через интерфейсы продолжается, если часть правил, маршрутов или записей ipset уже удалена.
- **Восстановление порядка правил.** MagiTrickle возвращает одиночный пропавший переход в `PREROUTING` на прежнее место, если его можно определить по соседним правилам. Это сохраняет приоритет групп.
- **Правка regex-правил.** После сохранения MagiTrickle применяет новое выражение в группах и подписках. Раньше могло продолжать работать старое выражение.
- **Совместимость wildcard.** Точка в шаблоне означает точку. `?` соответствует ровно одному символу. `*.example.com` соответствует поддоменам `example.com`. Чтобы включить и `anotherexample.com`, используйте `*example.com`. Для самого домена и всех поддоменов используйте Namespace `example.com`.

## Журнал OpenWrt

Обычные DNS-запросы больше не попадают в `daemon.err`. Ошибки демона сохраняют этот приоритет.

---

**Перед обновлением:** если вы меняли префиксы цепочек iptables или наборов ipset, проверьте, что в каждом минимум три символа.

**Установка / обновление на Keenetic (Entware):**

```sh
opkg update && opkg install wget-ssl ca-certificates
wget -qO- https://raw.githubusercontent.com/badigit/MagiTrickle_mod_badigit/mod_badigit/scripts/install.sh | sh
```

**Установка / обновление на OpenWrt:**

```sh
wget -qO- https://raw.githubusercontent.com/badigit/MagiTrickle_mod_badigit/mod_badigit/scripts/install.sh | sh
```

Дальше можно обновляться прямо из веб-интерфейса, кнопкой «Обновить».
